# Valheim Bow Animation Cancel

A simple AutoHotkey v2 script for Valheim's bow animation cancel.

## Requirements

Download and install **AutoHotkey v2**:

https://www.autohotkey.com/

> This script requires AutoHotkey **v2**.

## How to Use

1. Install AutoHotkey v2.
2. Download the `.ahk` script.
3. Double-click the script to run it.
4. Start Valheim.
5. Press **F8** to turn the macro **ON**.
6. Press **F8** again to turn the macro **OFF**.

A small notification will appear when the macro is turned on or off.

## Default Bindings

- **F8** — Toggle macro ON/OFF
- **B** — Animation cancel key

Make sure **B** is bound to the appropriate action in Valheim.

Open console in Valheim **F5**  type the following **bind key dance** so if you wanted to bind "V" 

Bind v dance
