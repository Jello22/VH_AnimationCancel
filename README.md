# Auto Hot Key Animation Cancel Script
AHK v2.0 AHK Script for valheim 

This is primarily used for bow training with the new target and works best with finewood bow.  Timings may need to be changed a bit for previous bow

F8 → toggle macro

PgUp/PgDn → tweak how long the click is held

F9/F10 → tweak how long before B fires

Home/End → quick reset
